OBJECTIVE
=========
Build and run a reproducible experiment campaign that starts from small static graph topologies and generates dynamic graph traces with controlled path lifetime, stability, and path-persistency properties. Replay each trace in ns-3 and compare network performance and measured dynamic-graph properties across parameter values, topologies, graph realizations, and routing protocols. The initial design uses a single S-to-R flow and simple topologies so expected plot patterns are interpretable.

RESULT INTERPRETATION / CAVEATS
===============================
Diagnostics showed the line topology has a single route and route-identity retention of 1.0. The two-lines topology showed route-retention response to path persistency. Measured lifetime and stability tracked their requested sweep settings. In the ladder persistency outputs, AODV PDR varied with persistency, while OLSR often reported zero PDR in the shown replays; interpret performance per protocol and topology rather than assuming every curve changes monotonically.

The earlier rough total estimate of 225 replay epochs was not the correct accounting basis. Verified campaign epoch count is 1,125: 3 topologies × 3 parameters × 5 sweep values × 5 graph realizations × 5 replay epochs. This is distinct from 225 aggregate replay CSVs, which correspond to 3 × 3 × 5 × 5 topology/parameter/graph/value cases. Each replay CSV contains the protocol results for a replay epoch.
