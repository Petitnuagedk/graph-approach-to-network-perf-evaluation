# Alpha A1 preregistration addendum 1 — count and seed-stream correction

**Registered 2026-10-09 before replacing the preliminary A1 graph set.** Original preregistration remains unchanged and hash-identified in `alpha/gates.md`. The first A1 wrapper run completed construction but a post-run identity audit found two design-record errors: (1) arithmetic in the original preregistration said 42 accepted graphs, although the declared design is 3 deterministic geodesics + 4 random families × 3 sizes × 3 realizations = **39**; (2) `base_seed + attempt` allowed adjacent realization seed ranges to overlap when an earlier realization was rejected, and the preliminary outputs contained repeated actual seeds (e.g. RGG N=162 r1/r2 both used 1,101,622; ER N=92 r2/r3 both used 1,300,924). Those preliminary outputs are superseded and will not be used as final A1 evidence.

Before final regeneration, use the following disjoint random-family seed bases instead: `10,000,000 + family_code*10,000,000 + N*10,000 + realization*1,000`, with the original family codes RGG=1, WS=2, ER=3, BA=4. Attempt seeds are base plus attempt index 0–999. This creates nonoverlapping seed blocks across family/N/realization while preserving the preregistered 1,000-attempt rejection budget, graph distributions, family targets, sizes, graph counts, WS calibration seeds/grid, measurements, and all numeric gates. WS calibration remains at its original separately preregistered 2,000,000 + N*100 + grid_index seeds.

This addendum corrects seed allocation and graph-count arithmetic only; it changes no threshold, graph target, inclusion rule, or reported covariate. The final graph set will be regenerated from the beginning with the amended nonoverlapping seeds, and all final A1 tables will be replaced from that corrected set. No A2 generation, ns-3, protocol variants, or generator edits are authorized.
