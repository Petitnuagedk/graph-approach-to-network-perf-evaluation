## Registered measures and acceptance checks

For every successful trace record: requested life; timeline U and K; observed Boolean up-run lengths, mean/max; actual total Boolean transitions; frame-pool counts; measured S–R route-existence fraction across the assembled 120 frames; absolute error from requested life; shortest-path hop count per frame (`NA` if disconnected); static skeleton S–R hop distance; shortcut fraction (fraction of frames with a route strictly shorter than the static skeleton distance); 120-frame time-respecting reachability; dilution (requested Boolean life minus time-respecting reachability); and canonical route sequence at each frame. Keep one row per trace/seed; report cell mean and sample SD (`ddof=1`) over the five seeds for numeric measures and per-frame/run-length summaries where defined. Also report all per-seed data; never report only aggregates.

1. **Timeline construction:** each trace has exactly U up frames and K up-runs; its transition count is inside the A2a support interval above. Any violation is a failure.
2. **S–R fidelity:** route-existence fraction must exactly equal Boolean up-count/120 because up pools contain only connected frames and down pools only disconnected frames; additionally absolute error from requested life must be <=.05, the already frozen Alpha fidelity tolerance. Any nonzero difference between the Boolean mask and assembled route-existence mask is a failure.
3. **No shortcuts:** shortcut fraction must equal exactly 0. Any value >0 is a provenance/measurement failure and stops interpretation; the frame sampler is constrained to skeleton edges.
4. **Pools / graph provenance:** both pools nonempty and all sampled edges subset of the hashed skeleton in every included trace. A failure is not imputed.
5. **Level 2 route diversity (primary p_edge=.5 only):** for each family×life, compare the full 120-frame canonical route sequences among the five A2b greedy-selected seeds. For each frame use the lexicographically smallest node-label sequence among all minimum-hop S–R paths, with `None` for disconnected frames; canonical route comparison includes all 120 positions. At least `ceil(.90*(1-1/M)*10)` of the ten unordered trace pairs must have different complete canonical sequences; M is A2a exact support for that family-independent life/stability cell. With the registered M this threshold is 9/10 pairs in all four lives. Report raw pair count out of ten and hashes. Separately report NetworkX insertion-order route-sequence disagreement; it neither replaces nor changes this canonical criterion. Apply A2b's Level 1 criterion (five unique schedules, greedy-5 mean D >= .90×exact-uniform expected D, largest candidate duplicate group <=20) together with this Level 2 rule for the final diversity verdict per family×life. Do not rerank families.
6. **Time-respecting reachability:** use the A2 predecessor definition: layers i=0..120 contain all 92 nodes; from each i<120 allow waiting at every node and traversal of an assembled frame-i edge; for each start layer i, success iff R is reachable from S at layer 120. Reachability is successful starts/120. Report life minus this value as dilution; these are not instantaneous connectivity or packet delivery. This is a measured descriptor, not a separate pass/fail threshold.
7. **p_edge sensitivity:** p_edge=.3 and .7 use the same seeds and otherwise identical settings. Report the same per-trace fidelity, pool, shortcut, hop, and temporal-reachability measures. The canonical Level 2 diversity criterion is evaluated at registered primary p_edge=.5; p_edge contrasts are descriptive and do not create a post-result pass threshold.

A2c operational PASS requires all 300 trace operations to complete within 60 seconds without retry, required pools and graph provenance valid, timeline construction/fidelity/shortcut checks pass, all per-seed and per-cell tables/configs exist, all exact source/graph/config hashes are recorded, and every primary p_edge=.5 family×life Level 2 criterion passes in conjunction with A2b Level 1. Any unmet condition is reported as FAIL/INCOMPLETE, not silently repaired; stop before A2d/A2e pending user direction. No protocol variants; no ns-3; stop before A3.
