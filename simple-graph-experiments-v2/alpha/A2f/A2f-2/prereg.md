# A2f-2 preregistration — isolated `(U,K)` timeline interface

Registered after A2f-1 was logged and before copying/modifying source or running tests. All changes/results are confined to `alpha/A2f/A2f-2/`. The source base is the A2d item 1 isolated tree; no upstream checkout, J2 `G2DG-SPC.py`, prior Alpha stage, or stored result is modified. No EM work, ns-3, protocol variants, or A3.

## Frozen interface and interpretation of rounding

New opt-in `behavior="uk"` has no stability argument. Inputs are exactly one of `up_count=U` or `path_life=q`, plus exactly one of `up_runs=K` or `mean_up_duration=m_up`. For life input, compute `U=round(F*q)` with Python round-to-even. For mean input compute `K_requested=round(U/m_up)` with Python round-to-even. For nontrivial `0<U<F`, validate `1 <= K_requested <= K_max=min(U,D+1)` before sampling; never clamp an invalid K. Trivial all-down support is exactly `(U,K)=(0,0)` and all-up support exactly `(U,K)=(F,1)`; a different K is infeasible (K_max=0 for U=0, K_max=1 for U=F). Mean-derived K is undefined for U=0 and must raise `ValueError`. This resolves the prior informal “clamped” wording against the binding no-silent-clamp/type-error rule: rounding calculates a request; feasibility validation rejects it without modifying it. `InfeasibleTimeline` exposes integer fields `U`, `D`, `K_requested`, and `K_max`.

For exact `K`, sample from the A0-R2 exact-uniform support using unchanged category weights `b(K,J)*C(U-1,K-1)*C(D-1,J-1)`, uniform positive compositions, and the existing boundary choice. `uk` and `patched-v2` use identical sampler code path and RNG consumption; at matching `(F,U,K,seed,pathPersistency)` the preregistered expectation is **bit-identical timeline and path-ID output**, not merely identical distribution. `patched-v2` explicitly aliases the historical A0-R2 `behavior="patched"`; `legacy` remains the A0-R2 historical behavior. Existing `patched-v3` frame sampler remains selectable in the copied item 1 source.

The legacy stability mapping is the A0-R2 rule `K=round(1+(1-s)*(U-1))`, bounded to `1..U`; for an explicitly requested feasible K and U>1, comparison stability is `s=1-(K-1)/(U-1)`. The interface never consumes s in `uk`. For U<=1, map to the only feasible K and label comparison stability undefined.

## Frozen test grid and numeric gates

1. **Support enumeration:** for F=8, enumerate all 256 Boolean strings and compare direct `(U,K)` counts with the closed-form support count for all U=0..8 and K=0..8 (81 pairs). Gate: 81/81 exact; all infeasible counts are zero; trivial all-up `(8,1)` and all-down `(0,0)` singleton counts are one, and their other K counts are zero.
2. **Seeded marginal test:** F=120, lives `{.3,.5,.7,.9}`; for each life, three exact K cells: shortest feasible mean-up (`K=Kmax`), geometric midpoint between that endpoint and the longest exact feasible mean-up not exceeding 30 frames, and that longest exact feasible mean-up (largest supported `U/K <=30`). Resolve the middle K by `round(U/sqrt(m_min*m_max))`; if duplicate K occurs, report and test the duplicate as independently seeded replicates rather than substitute another K. Seed set is every integer 42..241 (200/cell; 2,400 traces). For every trace, exact U and K gates are 100% (2,400/2,400), operation wall time <=60 s with no retries. For each cell, down-run-category chi-square Monte Carlo p-value uses 99,999 multinomial null draws from exact-uniform category probabilities and one fixed diagnostic RNG seed `20261010`; require p>=.01 in all 12 cells. If a cell has one supported J category, record the test as uninformative and assign p=1; it still must meet exact U/K and time gates. Save every seed row and a config for every trace.

The deterministic grid resolves to: life .3, `U=36`, K values 36 (m=1), 8 (midpoint target sqrt(18), realized m=4.5), 2 (m=18); life .5, U=60, K 60 (m=1), 11 (midpoint target sqrt(30), realized m=60/11), 2 (m=30); life .7, U=84, K 37 (m=84/37), 16 (midpoint target sqrt((84/37)*28), realized m=5.25), 3 (m=28); life .9, U=108, K 13 (m=108/13), 7 (midpoint target sqrt((108/13)*27), realized m=108/7), 4 (m=27). All are distinct within life and feasible.
3. **Mode regression:** use the 15 stored A2c ER (`er_N92_r1`) timeline/path-ID records with p_edge=.5 for life .3 seeds `{42,63,178,107,56}`, life .5 seeds `{42,98,90,126,236}`, and life .7 seeds `{42,228,199,235,44}`. For each, compare `legacy` and `patched-v2` from the new copy against the corresponding A0-R2 original output; require 15/15 exact timeline+path-ID equality for each mode (30/30 mode comparisons). Also compare `uk` at the equivalent exact K with patched-v2 for the same seed and persistency; require 15/15 exact equality.
4. **Typed infeasibility:** for every one of the 27 A2f-1 `(F,life)` cells, invoke K=`Kmax+1` in a separate operation and require the typed exception with exact fields and return/raise within 1.0 second (27/27). Also test mean-derived infeasibility at F=120, life=.9, m_up=4; require K_requested=27, K_max=13 and typed exception within 1.0 second (1/1).
5. **Patch/provenance:** isolated copy manifest and patch are complete; decompressed patch exactly matches its baseline-to-copy diff; dry-run applies to a separate clean A2d item 1-derived snapshot without mutation. No tests may alter A2d item 1 or A2f stored-result inputs.

Operation seeds are deterministic and recorded per config. The timeline's `seed` controls schedule/path IDs; any later trace stages use the documented single base seed with fixed, registered offsets (timeline `seed`, pool `seed+10000`, assembly `seed+20000`), not independent seed search. Sample SD uses `ddof=1`; persist per-seed results.

## Known risks and limitations

A2f-1 shows that no API can make unsupported `(U,K)` combinations feasible. The A2a stability mapping still confounds life and mean up-run; this interface changes the user control, not the physical support. Timeline diversity is family-independent by construction; the A2b gate is non-binding by construction (greedy max-min selection); Level 2 route diversity is tie-break-sensitive; time-respecting reachability permits waiting and is not an OLSR/AODV/DSDV oracle. Generator is an isolated patched non-upstream copy. 0 protocol variants, no ns-3, no A3.
