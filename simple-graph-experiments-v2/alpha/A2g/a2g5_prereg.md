# A2g-5 preregistration — fixed-duration offline operating region

Registered after logging A2g-4 and before calculating the fixed-duration operating table or synthesizing a recommendation. This is deterministic offline analysis of the already frozen A2f-1/A2f-2 and A2g-2 results. No new frame/pool operations, simulations, ns-3, protocol variants, or A3. All new artifacts stay under `alpha/A2g/`; do not modify historical artifacts or `alpha/EM/`.

## Fixed-duration design

Fix physical experiment duration at **120 seconds**. Compare only the two frame grids already supported by A2g-2: `(fps,F)=(1,120)` and `(2,240)`, where `F=duration×fps`. Frame duration is `Δt=1/fps`. A packet size of 1024 bytes at 50 kbps takes `1024×8/50000=0.16384 s`; two packet intervals are `0.32768 s`. Classify the frame grid as temporally resolved against this conservative two-interval yardstick iff `Δt >= 0.32768 s`. This is a time-resolution screen only, not protocol performance or a delivery guarantee.

For lives `{.3,.5,.7,.9}`, use exact `uk` quotas `U=round(F×life)`, `D=F−U` and a common **12-second target mean-up duration**. Its exact frame-domain target is `m=12×fps` and `K=U/m`; classify exact-quota feasible iff K is a positive integer no greater than `Kmax=min(U,D+1)` (A2f-1 support), with nontrivial U,D. Independently test the packet-interval target `m_packet=0.32768×fps` against the finite exact support `{U/K: K=1,…,Kmax}`; if it is not exactly in that support, label it unreachable, with no rounding/interpolation. Report minimum and maximum exact mean-up durations as `{U/Kmax/fps, U/fps}`. Use only the two frozen grids; do not extrapolate to another fps or F.

## Pool supply synthesis

Use only the 809 successful A2g-2 operation rows, their explicit one-cell external interruption status, and the existing A2g-2 p* summaries. For each family×N×trial count and F∈{120,240}, report the highest registered `p_edge` where all-life strict distinct-entry quota demand passes in all three seeds; preserve absent p* as NA. Also report the registered mean/sample-SD p* across seeds by graph and trial count. A strict quota pass is exactly the A2g-2 rule: F=120 requires up/down pool entries >=108/84; F=240 requires >=216/168. Do not substitute the assembler's with-replacement/nonempty-pool condition. Identify the candidate empirical region only as the finite set of observed graph/trial rows whose p* is defined; every point outside a row's p* is classified **not established as strict-supply-ready by these data**, not as physically impossible. The interrupted cell is not retried or imputed. Because H2 was not supported, do not claim a family-independent or monotonic supply law.

For a concise fixed-duration recommendation, assess the paired choices `(fps,F)=(1,120)` and `(2,240)` against the identical 120-second budget, the temporal-resolution screen, exact 12-second target feasibility, and the A2g-2 strict-supply evidence. Report whether each has evidence across all tested graph×trial rows; do not choose an unobserved p_edge or infer across graph realizations.
