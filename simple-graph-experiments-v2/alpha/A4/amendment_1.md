## 1. V1 packet identity correction

The A4.0B packet logs establish that `packets_<protocol>.csv` Tx `sequence` is global across clients, while the RX and forwarding logs carry the per-client `SeqTsHeader` sequence. Therefore Tx rows must not be assigned using the global sequence as a per-flow packet index. The frozen deterministic client schedule (warm-up + 0.1 + flow index / flow count; then the configured 0.16384 s packet interval) assigns each Tx event by its timestamp, only when there is one exact schedule match. The RX event timestamp is joined to that unique Tx timestamp; counted forward events additionally require the logged IP endpoints to match that scheduled flow. No heuristic or ambiguous assignment is accepted.

Replaying the original V1 clauses with that identity correction passes all three A4.0B protocols: all 4,371 Tx rows per protocol map uniquely and offered counts match; every Rx maps uniquely to a Tx and per-flow unique deliveries match; per-flow sequence values agree between RX and every corresponding forwarding event (zero sequence-identity inconsistencies); all delivered paths have consecutive A1 geodesic edges and exactly hops−1 counted forwarders; all forward events map to a Tx; and summed node-forward counters equal delivered plus undelivered forward events. OLSR: 4,181 delivered paths, 15,326 delivered + 8 undelivered forward events = 15,334 counters. AODV: 4,355 paths, 15,975 + 50 = 16,025. DSDV: 4,335 paths, 18,279 + 41 = 18,320. V2 and V3 remain unchanged and pass for all protocols. The original [validation_4.0.json](validation_4.0.json) is preserved; the corrected offline results are in [A4.0b](A4_0b/a4_0b_report.md).

## 2. A4.0A crash accounting and projection

Three of six A4.0A pilot attempts failed with assertion-class crashes, not timeouts: OLSR φ=1% and φ=10% both assert in OLSR `MessageHeader::Deserialize` (+10.720175795 s and +10.762525735 s), with the stack entering `ControlMessageKind` → `RecordControlTx`. These runs had instrumentation enabled, `a3bForwardLog=false`, and `dumpRoutes=false`; the OLSR signature is consistent with the control-message telemetry parser path, but the exact malformed packet/root cause is not established. AODV φ=10% asserts at +24.000100000 s because `ScheduleRreqRetry` asks ns-3 to schedule a negative delay. It is a different failure path; the reason the retry value became negative is unestablished. The wrapper forwards the child return code; SIGABRT's −6 is represented as shell status 250. The failed-run elapsed times are not valid completed simulation runtimes.

DSDV φ=10% independently fires the frozen saturation rule: median background PDR 0.0235947 <0.50 and max-degree retry ratio 0.8059319 >0.30. This selects the registered per-node fallback regardless of the preliminary runtime trigger. However, the registered φ=10% timing inputs for OLSR and AODV are incomplete, so the corrected 4.2 total runtime projection is **not estimable** from A4.0A; do not use the earlier derived pair/fallback hour estimates as valid projections. The per-node load-unit selection remains supported by DSDV's observed saturation metrics.

## 3. Convergence tail hypothesis

The original frozen detector was replayed on all three A4.0B logs and reproduces the stored values exactly (238.980381135 s OLSR, 238.980381192 s AODV, 238.980380856 s DSDV). In each run, the final five window evaluations are fail/pass/pass/pass/pass; the failing window is 61/62 (0.983871), followed by four passing windows. Each probe has zero unreceived Tx in the final 10 s and zero Rx logged after the 239 s stop. Total probe packets not received by stop are 67/9/12 respectively, but none is a final-10-second candidate in-flight packet. The tail-effect hypothesis is therefore **not supported by these observations**. Do not alter the detector or adopt a tail cutoff. A sensitivity-only truncation using the maximum observed one-way delay in the last 10 s plus one packet interval (0.16384 s) shifts convergence to about 238.81654 s; it is not an amended result. Existing immediate/delayed/never synthetic tests still pass; the additional synthetic tail case demonstrates only that a boundary artifact is possible in principle.

A4.0B is not A4.1 evidence: it is the preregistered N=42 V1 validation, and no A4.1 variant ran. A4.0A successful Part-A runs lack packet timing logs, so their saved convergence values cannot be replayed offline.
