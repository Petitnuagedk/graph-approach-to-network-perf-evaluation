# B1 adapted preregistration — A4.5 static equivalence

**Registered:** 2026-11-12. **Status:** blocked; preparation only; no B1 run.

B1 will compare N=42, seed 42, AODV and OLSR at path life 1.0, which is the A4.5 static reference and is not generated by YaDyGaGa. The comparison requires completed A4.5 seed-42 records before launch.

The exact gate is equality of configuration hash, trace/frame hash, probe PDR, background median PDR, and control totals against the corresponding A4.5 records. Any mismatch stops Beta. No tolerance, substitution, rerun, or interim decision is registered. B1 uses interpolation OFF, the 7B channel, phi 0.05, warm-up 120 s, sim time 300 s, and window [120,420].

Because A4.5 has no completed performance record—the 30 attempts stopped at the zero-swap pre-launch guard—B1 is not launchable. This preregistration contains no command that starts a simulator.
