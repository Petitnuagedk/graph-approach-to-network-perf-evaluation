# Beta cap stop

The existing Beta charter records a cap of 500 protocol variants. The newly registered exact design requires 600 Phase 1 dynamic variants and 2,400 Phase 2 variants, for 3,000 total. Phase 1 therefore exceeds the cap by 100 variants.

This is a preparation-stage stop. The design is not reduced, the cap is not changed, and no Beta run is launched. An explicit user decision is required before any execution planning can become executable. B1 is independently blocked because A4.5 has no completed static seed-42 AODV/OLSR result.
