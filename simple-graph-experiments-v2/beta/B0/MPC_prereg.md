N=42 r1 family: 44 ordered pairs are produced, with the probe first and the
same `mt19937_64` shuffle and orientation draw as ns-3. The first 44-pair MPC

registered life/stability timeline still requires a separate B0 acceptance run.

## Objective

Replace SPC with MPC so the dynamic graph is constrained against the same complete traffic-pair set that produces the protocol traffic under `phi`.

## Pair-set identity

For each family and N=42 realization r1:

1. Read the A1 probe pair `(probe_S, probe_R)` from `graph_covariates.csv`.
2. Freeze the complete ns-3 pair set generated by the exact `GenerateFractionFlowPairs` rule in `sp1-sp2/scratch/graph-run.cc`.
3. Use `phi=0.05`, `allPairs=N(N-1)/2`, `llround` semantics, the probe pair first, and the registered row flow seed.
4. Preserve source/destination direction exactly as generated; MPC pair identity is ordered for traffic but reachability/path evaluation uses the same endpoints.
5. Store the frozen pair list and a SHA-256 manifest before MPC B1/B2.

At N=42, `llround(0.05 * 861) = 43` background pairs, plus one explicit probe pair, producing 44 traffic pairs per run.

## MPC construction

Pass the exact 44-pair set to `FrameGenerator.generateMPCFrames`. The returned `per_pair` records are authoritative for pair-specific frame availability and path identity. Generate the `MPCTimelineBlockGenerator` timeline with 44 pair entries and build frames with `MPCDynamicGraph`.

The first implementation must run with `force=False` and no Hamming or arbitrary-frame fallback. Any missing exact status tuple or unsatisfiable path-ID constraint is recorded as infeasible; it is not silently substituted.

## Required checks

- Exact equality between the frozen ns-3 traffic pairs and `MPCFrameSet['pairs']`.
- Pair order and direction preserved.
- Every selected dynamic frame's status and per-pair path identity checked against `MPCFrameSet['per_pair']`.
- Per-pair realized life, up-run count/stability, path-ID persistence, and fallback count recorded.
- No protocol run until pair-manifest and MPC generator checks pass.

## Scope

Five N=42 r1 families, seed 42 for B0/B2 characterization, fixed pool `p_edge=0.5`, trials 10,000, pool seed 11, A0-R2 pinned build, and `behavior="patched"` where applicable. B1 will use the A4.5 static reference only after MPC pair construction is proven equivalent. B3 remains stopped.
