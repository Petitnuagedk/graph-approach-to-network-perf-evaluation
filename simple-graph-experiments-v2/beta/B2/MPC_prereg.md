# MPC B2 pair-aware characterization

**Date:** 2026-11-13  
**Status:** pending implementation and smoke validation

B2 is repeated under MPC. It uses the exact frozen `phi=0.05` traffic-pair set for each N=42 family, not only the A1 probe pair. The pair set contains 44 ordered traffic pairs: the explicit probe plus 43 background pairs generated by the ns-3 `GenerateFractionFlowPairs` rule.

For every characterization row, `FrameGenerator.generateMPCFrames` receives that same pair list. The MPC timeline has one state/path-ID coordinate per traffic pair. `MPCDynamicGraph` is required to select frames satisfying the exact status tuple and per-pair path identity constraints. Fallbacks, clamping, substitution, and arbitrary-frame selection are forbidden; failures remain visible as infeasible.

The B2 output must include the pair-manifest hash, exact pair list, per-pair up count, realized life, up-run count, realized stability, path-ID retention, selected frame indices, exact-status match, and fallback count. A protocol result is not accepted until the ns-3 flow list and MPC pair list are byte-for-byte equivalent after canonical CSV normalization.

Fixed scope: five N=42 r1 families, characterization seed 42, `p_edge=0.5`, trials 10,000, pool seed 11, pinned A0-R2 source, no protocol variants charged. This supersedes the SPC B2 characterization for the operative Beta campaign.
