# Beta cap stop

The existing Beta charter records a cap of 500 protocol variants. The newly registered exact design requires 600 Phase 1 dynamic variants and 2,400 Phase 2 variants, for 3,000 total. Phase 1 therefore exceeds the cap by 100 variants.

This stop was resolved by an explicit user decision on 2026-11-13: the cap is raised to 1,200 protocol variants. The 600-variant Phase 1 design is within the amended cap. The 2,400-variant Phase 2 design remains above the amended cap and remains stopped unless separately authorized. No design row was silently removed or substituted.

B1 is no longer blocked by A4.5: the completed A4.5 amended ledger contains the required static seed-42 N=42 AODV/OLSR records. The cap amendment authorizes B1 only; it does not authorize the Beta sweep.
