# Phase 7 / Alpha gate decisions and evidence limits

**Updated 2026-10-08.** This is a retrospective decision record; it does not overwrite preregistrations or alter any raw result.

## 7B disposition

**Disposition: 7B accepted by the user on 2026-10-08 as passed via B1′ and B2, with the original B1 failure retained explicitly.** The frozen B1 aggregate-PDR versus no-interpolation usable-uptime tolerance was 0.05 per alternating-trace run. All three B1 runs had PDR 0.749513 and usable uptime 0.507640068, an absolute difference of 0.241873; therefore **B1 failed its original frozen criterion**.

B1′ is a distinct deadline-qualified statistic with τ=50 ms and a 0.05 tolerance. Its preregistration was written **after B1 results had been inspected**. Accordingly, B1′ is post hoc relative to B1 and is not represented as a blind or prospective repair of the B1 result. The exploratory calculation on the saved B1 runs was not confirmation. The three separately run B1′ confirmation cases passed their own frozen criterion: Qτ=0.507093185 versus usable uptime 0.507640068, absolute difference 0.000546883 in each case, with the recorded event/config/frame-integrity checks passing. **The project decision recorded here accepts B1′ as the replacement deadline-qualified reference gate for 7B.** This acceptance does not change the B1 result or its failed tolerance. B2 independently passed the legacy deterministic regression: one invocation with OLSR/AODV/static (3 variants), 15 deterministic output files byte-identical to B0, no comparison mismatches, and result rows identical after excluding only wall/CPU columns. Thus 7B is marked passed under the accepted B1′ criterion plus B2, while its original B1 aggregate-PDR criterion remains failed. Evidence: [B1 preregistration and results](7B/prereg.md), [B1′ preregistration](7B/B1prime_prereg.md), [B1′ fresh confirmation](7B/B1prime/confirmation_summary.json), [B2 comparison](7B/B2_comparison.json), and [B2 invocation evidence](7B/B2_invocation_record.json).

## 7D generator validation: what the pass establishes

- **Threshold provenance:** the numeric acceptance rules (exact S–R-up quota; five distinct nondegenerate timelines among five IDs; mean pairwise normalized Hamming distance at least 0.10; repeatability and persistency/stability checks) are written in [the 7D preregistration](7D/prereg.md), which states it was registered before implementation and trace generation on 2026-10-08. The preregistration was prepared in this project workflow (by the assistant/project agent); it does not name a human co-author. The thresholds were not selected after seeing the generated traces.
- **Diversity statistic:** the validator derives one Boolean per frame by running a route/reachability check from S to R, then computes uniqueness and Hamming distance on those 60-bit S–R sequences. It does **not** use whole-matrix serialized-trace differences as the diversity statistic. See the `_bits` and diversity calculations in [the validator](7D/validate_generator_v2.py) and the per-cell results in [cell_summary.csv](7D/cell_summary.csv).
- **Scale:** tested only 60-frame Phase 5-derived small topologies: line, N=5; two-lines, N=8; ladder, N=8. This does not test N=92 seed diversity or N=162 generation time. The separate timing smoke test was also only a 5-node static replay. Consequently, these results do **not** establish Alpha A0 criteria (c) or (d), generator usability at Alpha scale, or a runtime projection.

## Generator source boundary and disclosure

The validated Phase 7D implementation is a **new standalone module** at [generator_v2.py](7D/generator_v2.py), with a separate [offline validator](7D/validate_generator_v2.py). The validator imports this module; it does not import or execute `G2DG-SPC.py` or YaDyGaGa. It assembles traces from saved Phase 5 up/down frame pools. Therefore the reported 7D validation itself did not edit or exercise the legacy generator implementation. The separate existing-file worktree modification and its unresolved provenance are disclosed above; no changes to that file were made as part of this gate-record update.
